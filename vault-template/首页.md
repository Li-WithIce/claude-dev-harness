# 助理工作区

这是 Dev Harness 的可选稳定记忆工作区。当前任务以项目本地 v2 Runtime 为准，Memory 不决定协议、任务状态或执行权限。

## 快速导航

- [[配置/系统信息]]：系统边界。
- [[配置/用户偏好]]：已确认的稳定偏好。
- [[配置/工具与组件]]：工具与组件说明。
- [[工作流/项目约定]]：项目长期约定。
- [[工作流/共享记忆协议]]：Memory 与 v2 任务状态的边界。
- [[工作流/记忆管理协议]]：经授权的候选提升和归档。
- [[运行时/记忆候选]]、[[运行时/记忆候选归档]]：长期记忆候选，不是任务镜像。
- [[运行时/收件箱]]：经授权捕获的业务事项，不自动执行。

## 任务恢复

明确的状态/恢复请求选定 v2 后，使用原生只读入口：

```powershell
pwsh -NoProfile -NonInteractive -File "{VAULT_PATH}\entry\task.ps1" status -AsJson
```

新任务不读取旧恢复索引或任务镜像。继续执行需要另有授权；status 不更新指针。已有 v1 plan 只能显式迁移为 paused，不能从记忆入口复活 v1。

## 能力状态

此模板不证明任何 Host、Provider、Memory 写入或 Release Gate 已验证。可选能力须以实际安装和当前请求授权为准；保留的旧文件也不等于活动运行时。

# 恢复协议

## 请求分类

- `刚才做到哪里了` / `what were we doing` / status：只读恢复查询，只关联已有 task identity 并返回摘要，不获得执行或写回权限。
- `继续` / `继续刚才的任务` / `恢复并执行` / `continue` / `resume-and-execute`：明确继续已有 workflow；通过 [[工作流/任务识别协议]] 确认 identity 与 write-authorized `mode=workflow` 后，才允许 replay、repair、sync/activate、写回或加载 stage skill。
- `恢复一下` / `resume` 若无法判断是查询还是执行：走 ask，不写 runtime。

显式任务切换或新任务判断优先遵循 [[工作流/任务识别协议]]；route identity 不扩大请求授权。

## 读取顺序

0. 先只读 `运行时/收件箱.md` 中 open `[writeback-fallback]` 的元数据。只读恢复查询不重放；只有明确继续执行 write-authorized workflow 时，才在命中目标 task 后读取其 `plan.md` frontmatter，并以相同 `TaskId/ExpectedStage -SyncOnly` 收敛。普通 advance 不得代替重放。

## 派生视图标记

- `恢复索引.md` 与 `中断任务.md` 是派生视图，frontmatter 必须声明 `derived_from: [...]`
- reader 在读取派生视图前必须做时间戳一致性检查；只读查询发现过期时报告 stale，不写回
- 如果 current pointer 或合法 task mirror 的 `updated` 晚于派生视图 `updated`，只有明确继续执行 write-authorized workflow 时才由 repair 刷新恢复索引；不得用 legacy current-flow 覆盖已有 pointer

1. 优先读取 [[运行时/恢复索引]]
2. **一致性检查**：比较 `恢复索引.md` 的 `updated` 时间戳与 `当前任务.md`、合法未完成 task mirror 的 `updated` 时间戳
   - 如果任一 canonical source 的 `updated` > 索引的 `updated` → 索引可能过期；只读查询报告 stale 并改读 canonical source，明确继续执行时才由 repair 刷新
   - 获得 write-authorized workflow 权限并刷新后，重新读取更新后的索引
3. 若索引信息不足，再读取 [[运行时/当前任务]]（共享指针）
4. 按共享指针中的 `task_id` 读取 `运行时/tasks/<task-id>.md`（任务级详细状态）
5. 然后读取 [[运行时/中断任务]]
6. 最后读取 [[运行时/上次会话]]
7. 如有命名检查点，再补充检查对应文件

## Resume 懒加载

- 恢复路径只加载 open `[writeback-fallback]`、`恢复索引.md`、`当前任务.md`、`运行时/tasks/<task-id>.md` 和当前任务的最小 stage 线索。
- 需要确认 stage 时，只读当前任务的 `docs/tasks/{task_id}/plan.md` frontmatter，不扫描全部 `docs/tasks/*`。
- 只读恢复查询判定当前 stage 后直接报告，不加载 stage skill；只有明确继续执行 write-authorized workflow 时才加载对应 stage skill，不预加载全部 stage skill。
- 不加载 Claude 兼容 skill 或 `workflow-team`，除非当前任务 frontmatter、显式 backend override 或 team-mode env 命中。

## 恢复回复格式

恢复回复必须使用三段式结构，用分隔线 `---` 分隔：

### A. 当前主任务
```text
task: ...
progress: ...
next step: ...
```

### B. 其他中断任务（如有）
```text
task: ...
priority: ...
progress: ...
next step: ...
```

### C. 恢复选项
```text
1. 继续当前主任务
2. 切换到 [P1/P2] ...
3. 按编号切换到其他中断任务
```

## 规则

- 索引用于快速恢复，不替代运行时真相源
- 第一行先给主任务，不先讲背景
- 若 `当前任务.md` 与 `中断任务.md` 冲突，以 `当前任务.md` 为主
- 若 `中断任务.md` 的恢复选项与共享指针不一致，视为派生视图过期，优先提示入口 agent 刷新
- 若 `当前任务.md` 为空且 `上次会话.md` 标记未收尾，优先提示用户从中断任务继续
- 使用中文回复，除非用户明确要求切换语言

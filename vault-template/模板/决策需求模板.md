# 决策需求模板

> [!tip] 使用方法
> 只有在自动推进必须暂停时才创建 `.assistant/orchestration/decision-needed.md`。
> 文件不存在表示当前没有 open decision；不要预先放一个空壳文件占位。

```markdown
---
schema_version: 1.0
task_id: <task-id>
status: open
summary: <short blocking summary>
requested_by: <entry host>
updated: YYYY-MM-DD HH:mm:ss
---

# Decision Needed

## Context

- stage: <PLAN|PLAN_REVIEW|IMPLEMENT|CODE_REVIEW|TEST|DONE>
- current_doc: <docs/tasks/{task_id}/*.md|none>
- blocking_reason: <why automatic progression must stop>

## Options

1. <option A>
2. <option B>

## Recommended Path

- <recommended option and reason>

## Needed From User

- <what must be confirmed or chosen>

## Resume When Resolved

- <how the workflow should continue after the decision is made>
```

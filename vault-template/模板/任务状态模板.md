# 任务状态模板

> [!tip] 使用方法
> 创建新的 `运行时/tasks/<task-id>.md` 时，优先从此模板生成。
> 新写入 `stage` 只使用当前 harness-lite 的合法阶段；历史多阶段命名不再写回新任务文件。

```markdown
---
tags: [运行时, 任务]
created: YYYY-MM-DD
updated: YYYY-MM-DD HH:mm:ss
task_id: <task-id>
task_name: <task-name>
schema_version: task-runtime/v1.1
workspace: <absolute-workspace-path>
writer: Claude Code | Codex
entry_host: claudecode | codex | team-leader
---

# <task-id> — <task-name>

## 基本信息

| 项目 | 值 |
|------|-----|
| task_id | `<task-id>` |
| 工作区 | `<absolute-workspace-path>` |
| artifact_root | `docs/tasks/<task-id>/` |
| primary_artifact | `docs/tasks/<task-id>/<current-main-artifact>.md` |
| schema_version | `task-runtime/v1.1` |
| orchestration | `docs/tasks/<task-id>/plan.md` |

## Artifact Links

- primary: `docs/tasks/<task-id>/<current-main-artifact>.md`
- related:
  - `docs/tasks/<task-id>/spec.md`（optional delta-spec）
  - `docs/tasks/<task-id>/plan.md`
  - `docs/tasks/<task-id>/test.md`

## 当前状态

- stage: <PLAN|PLAN_REVIEW|IMPLEMENT|CODE_REVIEW|TEST|DONE>
- runner: <tool>
- 进度: <text>
- 下一步: <text>

## 关键上下文

- <key context>

## 阶段历史

| 时间 | 阶段变化 | 说明 |
|------|----------|------|
| YYYY-MM-DD HH:mm | BOOTSTRAP | <summary> |
```

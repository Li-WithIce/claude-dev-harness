# 敏感信息规范

## 目标

明确哪些信息不应进入共享 Obsidian 记忆仓库，降低同步、截图、日志与后续接入版本控制时的泄露风险。

## 禁止写入

- API Key / Access Token / Refresh Token
- 内网账号密码
- Cookie / Session / 授权头完整值
- SSH 私钥、证书私钥、数据库真实口令
- 含完整敏感参数的连接串

## 允许写入

- 工具路径
- 组件状态
- 脱敏后的主机名、库名、账号名占位符
- “凭证位于哪里”的路径说明，但不写凭证值本身

## 推荐做法

1. 共享记忆只记录“存在什么凭证、用于什么系统、由谁维护、放在哪个本机私有位置”
2. 真实 secret 放在工作区外部安全位置，或本机私有 `.env` / `.env.local` / `*.local.md`
3. 如果未来接入 Git、网盘或团队同步，优先把私有目录和 `.env*` 排除出同步范围
4. 日志、测试证据、截图写回前先做脱敏

## 路径约定

- 共享可读：`.assistant/配置/*.md`、`.assistant/运行时/*.md`、`docs/tasks/**`
- 私有建议：工作区外部凭证管理器、本机环境变量、未纳入同步的 `*.local.*`

## 审核规则

- 发现疑似 secret 时，优先删除值，保留用途说明
- 不在 `配置/*.md`、`运行时/*.md`、`docs/tasks/*.md` 中粘贴完整 secret
- 若必须记录示例，使用 `***` 或 `<redacted>` 占位

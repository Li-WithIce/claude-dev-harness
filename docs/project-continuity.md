# 项目连续记录与工作接续

项目明确接入后，Harness 在代码改动前记录要求，在关键步骤后保存进展，新会话和压缩后先读取记录再继续。记录直接保存在项目文件中；不需要 Hook、Obsidian 或额外服务。

## 接入

1. 选择实际 Git 仓库内的文档位置。单仓库通常用 `docs/project-context.md`、`docs/changes/` 和 `docs/operations/`；多仓库产品选一个共享文档归档位置，分别关联各仓库提交。
2. 在会话工作区创建用户维护的 `PROJECT.md`，声明 `harness_continuity: enabled`，用相对链接指向项目说明。安装器只生成读取规则，不创建、覆盖或删除这个文件。
3. 从组件仓库单独开始会话时，在该仓库添加同样简短的 `PROJECT.md` 指向同一份说明；同时提供最小 `AGENTS.md`，要求读取 PROJECT 和产品入口规则。多个入口不复制正文或进度。
4. 使用 [项目模板](../templates/project-continuity/PROJECT.md.template)、[项目说明模板](../templates/project-continuity/project-context.md.template)、[变更模板](../templates/project-continuity/change.md.template) 和 [操作模板](../templates/project-continuity/operation.md.template)，替换为已核实事实。接入授权涵盖随后已授权开发任务的业务记录维护，不包括向其他外部记忆服务写入。

`PROJECT.md` 只作项目导航与显式接入标记。文档采用项目既有 Git 提交流程；没有提交时标记本地未提交，不能声称已经推送或远端可恢复。

## 读取与写入时机

| 场景 | 读取 | 写入 |
| --- | --- | --- |
| 新需求 | 项目说明、本次相关规范 | 改代码前记录要求、原因、范围、验收；原因不明就注明 |
| 继续工作或压缩后 | 本次相关变更记录及实际工作树 | 关键步骤后记录完成项、验证、下一步；不把时间最新的文件自动当作当前任务 |
| 重复打包、启动或发布 | 对应操作说明和既有脚本 | 记录本次实际结果；方式必须改变时解释原因，验证后更新现行说明 |
| 追问历史原因 | 项目记录；必要时用本地 recall/read | 只读请求零写入 |
| 完成本轮或交接 | 回读已保存记录 | 补齐未完成项、未验证项、每个仓库的实际修订与后续动作 |

一次独立改造一份记录，不把每次编辑拆成任务。小修复可用数行概述。记录当前工作时保留原要求和关键决定，后续需求追加日期与变化原因。现行规范更新后链接产生该变更的记录；真正被替代的规范可使用现有 `superseded_by`。

固定操作入口直接读，不依赖搜索命中。历史检索使用工作区 `.assistant/entry/context.ps1 recall -Query <关键词>`，然后 `read -Ref <引用>`。检索结果只是参考，必须回到原文件和当前代码；无结果就说明缺口。共享文档位于父产品工作区时，使用 PROJECT 声明的产品入口进行检索，不自动搜索无关仓库。

## Direct 与 Governed

业务变更说明属于项目交付文档，和修改 README 一样，不是机器任务状态。这类记录不设置 `Persistence=durable` / `DurableArtifactsRequested`，不使 Direct 自动升级，也不创建 `.assistant/runtime`、current pointer、Evidence 或额外生命周期。

用户要求正式机器状态、Evidence 或策略要求治理时，仍走现有 Governed/Critical。项目记录链接 canonical task/Evidence；状态以 v2 task state 为准，不能从一段摘要驱动状态转换。

当前用户要求优先于历史记录。记忆不能授权生产发布、数据库写入或停服务。敏感配置只记录位置、变量名和加载顺序，不复制真实值。构建成功、测试通过、打包完成与部署成功分开记录。

## 完成标准

换窗口后能找回要求与下一步；重复操作使用已验证入口；从变更记录能定位代码提交与验证结果。确定性脚本检查只证明文档检索、路由和分发；真实新会话、上下文压缩仍需宿主观察。未运行就标 `not_run`，没有证据不称为通过。

恢复以最后一个已保存检查点为准。异常终止前没有落盘的步骤，通过实际 diff 和产物重新核实，不补写成已完成。安装更新保留项目文件；撤销 PROJECT 的接入标记可以停止新的自动记录，已有历史仍保留。

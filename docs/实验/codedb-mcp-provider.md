# codedb-mcp Provider

Status: experimental and disabled by default.

## Boundary

- manual setup only
- no vendor until license is confirmed
- no auto-register MCP
- no harness install/update integration
- no default README quickstart
- no stage whitelist integration
- advisory-only

## Use When

- a large repository needs heavyweight code DB exploration
- DeepWiki/Atlas style context is explicitly selected
- license and operational cost are understood

## Review Rule

Review must check license, index size, MCP registration, and rollback before recommending codedb-mcp for any task.
